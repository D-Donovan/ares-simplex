# ARES simplex test - who can I hear?

A small web page for the RARC ARES simplex test. Each member sets their own station, logs the stations they hear
on simplex, and sees them on their own map (distance, direction, printable). Everything a member enters stays in
their own browser.

Station positions come from [aprs.fi](https://aprs.fi/) through a small lookup service; the aprs.fi key is kept on
that server and is not in this repository. Position data courtesy of aprs.fi. Map (c) OpenStreetMap contributors.

Page: https://d-donovan.github.io/ares-simplex/
